# 03. MedicalStudio 桌面 GUI 工具箱规划（Tauri 2.0）

## 1. 架构选型理由

选用 **Tauri 2.0（Rust 后端 + Vue 3 / React + Tailwind CSS 前端）** 构建 `crates/medical-studio`：
- **零中间层直调**：Tauri 的 Rust 后端直接依赖同 Workspace 的 `medical-core` 与 `medical-pipeline`，导入几十 GB 医学书籍或百万行病历时直接走本地多线程处理，不经过 HTTP 上传瓶颈。
- **交付轻量化**：打包为几 MB 的 Windows/macOS 原生桌面程序，医院信息科、感控科和运营人员双击即可使用。
- **体验极佳**：现代 Web UI 能够轻松呈现树状书籍切片预览、脱敏对比表格、实时进度条和 ECS 白盒调试面板。

---

## 2. 六大核心功能模块规划

### 模块一：📚 医学知识库与书籍导入工坊
- **多格式拖拽导入**：支持拖入整个文件夹（JSON/JSONL 采集包、Markdown、TXT、PDF、DOCX）。
- **切片可视化预览**：导入前可预览自动按“疾病 / 临床表现 / 鉴别诊断 / 急症指征”切块后的卡片列表，支持人工调整切块正则规则与元数据（适用人群、科室、权威等级、季节标签）。
- **高并发入库监控**：实时展示 `rayon`/`tokio` 处理速率（条/秒）、已完成/失败计数、错误日志导出以及**断点续传**按钮。

### 模块二：🧑‍⚕️ 病人历史数据批量导入与脱敏中心
- **文件读取**：支持医院导出的 Excel (`.xlsx`)、CSV、标准 JSON 病历包。
- **可视化字段映射**：拖拽或下拉将表格列映射到系统标准字段（如 `patient_id`、`age_group`、`chronic_diseases`、`allergies`、`visit_history`）。
- **隐私脱敏防火墙（入库前强制预览）**：
  - 自动检测并高亮敏感列（姓名、身份证号、手机号、详细住址）。
  - 提供脱敏策略：一键剔除 / 单向加盐哈希（生成匿名 `patient_id`） / 年龄转年龄段。
  - 确认脱敏预览无误后，批量写入 PostgreSQL（L2 画像）与 Qdrant（L3 历史事件）。

### 模块三：🦠 季节与流行病上下文控制台
- **可视化开关面板**：按城市/院区配置当前季节与高发传染病/季节病（如甲流、乙流、支原体肺炎、诺如病毒、过敏性鼻炎、中暑等）。
- **权重调节**：通过滑块调整每种流行病的当前强度（`0.0 ~ 1.0`）以及关联的优先追问模板。
- **热更新推送**：点击保存后直接更新数据库并通知 `medical-server` 刷新 ECS `EpidemicConfig` Resource，秒级生效无需重启服务。

### 模块四：🚨 关键词与急危重症词典管理器
- **双词典维护**：
  - 口语 -> 标准医学术语同义词映射表；
  - 急诊 120 红线词表（支持单关键词与多关键词组合规则）。
- **实时测试沙盒**：内置输入框，输入任意患者口语（如“老人突然胸口撕裂样疼出冷汗”），即时高亮命中的标准词条与触发的急诊等级。

### 模块五：🧪 ECS 分诊白盒调试台（Sandbox）
- **模拟环境配置**：选择测试病人（加载其真实/模拟的 L2/L3 长期记忆）+ 模拟当前季节与流行病环境。
- **左右分栏透视**：
  - **左侧**：模拟微信小程序聊天窗口（验证短追问字数是否 ≤ 30 字、快捷选项按钮体验、最终科室推荐卡）。
  - **右侧（ECS Inspector）**：实时列出当前 `TriageSession` 实体上每个 `Component` 的原始数据——`ExtractedSymptoms`、`RedFlagAlert`、`RagEvidence`（含 Rerank 原始分与季节加权后得分）、`TriageSlots` 状态变化，便于精准调优分诊逻辑。

### 模块六：🤖 AI 大模型与开放 API 网关配置中心
- **多模型 Provider 管理**：可视化添加/编辑多个上游大模型 API（云端 DeepSeek/Qwen/Gemini 或院内私有化 vLLM/Ollama）、Embedding 与 Rerank 端点，支持一键连通性与首字延迟测速。
- **路由与降级策略**：通过下拉框分别指定 `Fast Tier`（Query 改写/病历摘要）与 `Reasoning Tier`（核心分诊）的主备模型及超时阈值。
- **对外 API Key 签发与用量统计**：为微信小程序、医院 HIS 或第三方应用生成/吊销 API Key，配置 QPM/TPM 限额，并实时查看各模型 Token 消耗与错误率图表。
