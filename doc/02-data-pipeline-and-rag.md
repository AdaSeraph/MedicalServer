# 02. 纯 Rust 数据管线、长期记忆与混合 RAG 设计

## 1. 海量医学书籍与数据集导入管线（`medical-pipeline`）

所有数据采集、清洗、切块与入库均采用**纯 Rust** 实现，支持通过 CLI 或 Tauri 桌面端调用，具备断点续传与多核并发能力。

### 1.1 管线处理阶段（同样采用流式 + 并行批处理）
1. **多源解析器（Parsers）**：
   - **JSON / JSONL 采集包**：使用 `sonic-rs` 进行 SIMD 极速流式解析，直接校验是否符合 `doc/schemas/data-collection-schema.json` 规范。
   - **医学书籍（Markdown / TXT / DOCX / PDF）**：使用 `pulldown-cmark`、`docx-rs`、`lopdf`/`pdf-extract` 提取层级标题与正文（扫描版 PDF 预留 OCR 插件接口）。
   - **医院历史病历（Excel / CSV）**：使用 `calamine` 和 `csv` 高速读取，结合 `rayon` 并行执行隐私脱敏。
2. **医学语义结构化切块（Medical Chunker）**：
   - **禁止按固定字数机械截断**：按医学知识树切分为独立逻辑块：`疾病名称 -> 临床表现 / 鉴别诊断 / 急症指征 / 推荐科室 / 流行病学特征`。
   - **强制元数据注入**：每个 Chunk 绑定 `target_population`（成人/儿童/孕妇/老人）、`department`（科室）、`authority_level`（教材/指南=1.0，问答集=0.6）、`seasonal_tags`（如 `["influenza", "winter"]`）。
3. **双引擎并发写入**：
   - **向量化**：支持本地 `fastembed-rs`（ONNX 运行 `BGE-M3`）或批量并发调用云端 Embedding API，写入 **Qdrant**（按元数据建 Payload Index）。
   - **全文索引**：同步写入 **`tantivy`**（集成 `tantivy-jieba` 中文医学分词），用于医学专有名词的精准 BM25 召回。

## 2. 病人「长期记忆」三层存储与召回机制

为了兼顾**跨月/跨年复诊记忆**与**单次推理低延迟**，采用三层记忆架构：

| 记忆层级 | 存储介质 | 数据内容 | 生命周期与更新方式 |
| :--- | :--- | :--- | :--- |
| **L1 短期工作记忆** | Redis | 当前问诊的实时多轮问答、槽位状态 | TTL 24 小时，对话期间实时读写 |
| **L2 长期健康画像** | PostgreSQL（加密字段） | 年龄段、性别、孕产史、慢病史、过敏史、长期用药 | 长期留存（支持患者一键注销）；每次会话结束异步增量合并（Upsert） |
| **L3 长期事件记忆** | PostgreSQL + Qdrant | 历次分诊摘要（时间、主诉关键词、分诊科室、后续反馈） | 长期留存；仅当新主诉与历史事件语义相关时按需召回 Top-3 |

### 下一次分诊如何调用长期记忆？
1. 患者发起新分诊 -> 自动加载 `L2 长期健康画像`（必选，约 100~200 Tokens）。
2. 使用患者本次主诉检索 `L3 长期事件记忆` -> 召回相关历史记录（例如：3 个月前曾因“反复上腹痛”分诊消化内科）。
3. **Query 改写**：将 `本次主诉 + L2 关键慢病/人群 + 召回的 L3 事件` 合并为结构化查询向量与关键词，再进入知识库检索。

## 3. 关键词识别、流感季节加权与短追问策略

### 3.1 关键词与口语标准化
- 启动时从数据库/JSON 加载医学同义词库，构建 `aho-corasick` 自动机驻留内存。
- 毫秒内完成两件事：
  1. **急危重症拦截**：命中胸痛放射左臂、呼吸窘迫、咯血、昏迷、自伤等高危组合，直接返回 `Emergency120`。
  2. **口语转术语**：如“心口窝疼” -> `上腹痛/心前区痛`，“拉水” -> `水样便`，显著提升海量医学书籍的召回率。

### 3.2 结合流感季节与流行病学上下文
- 维护动态配置表 `epidemic_contexts`（包含地区、季节、当前高发疾病列表、流行强度 `0.0 ~ 1.0`、关联症状标签、优先排查追问项）。
- **两处生效**：
  1. **检索重排加权（Rerank Boost）**：当召回的医学书本条目 `seasonal_tags` 命中当前地区高发疾病时，最终得分执行动态加权：`final_score = rerank_score * (1.0 + alpha * epidemic_intensity)`。
  2. **追问引导**：将当季高发背景（如“当前本地处于冬季甲流与支原体高发期”）注入 System Prompt，引导模型优先排查接触史或典型伴随症状。

### 3.3 「短而准」的智能追问规范
为避免患者阅读疲劳，强制通过槽位状态机 + JSON Schema 约束大模型输出：
- **单次仅问 1 个核心问题**，正文严格 **≤ 25~30 个汉字**。
- **必须附带 2~4 个快捷点击选项**（如 `["今天刚开始", "2~3天", "超过1周"]`），供微信小程序渲染为一键回复按钮。
- **最多追问 3~4 轮**，达到上限或候选科室置信度超过阈值时，立即收敛并输出结构化分诊结果。
